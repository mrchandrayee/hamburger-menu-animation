A responsive, standalone recreation of the uploaded screen recording.

## Animations included
- Squeeze Animation
- 3D Flip Animation
- Arrow Animation
- Slide Out Animation
- Plus Match Animation

Click each hamburger icon to toggle between the three-line menu and its animated state. Each card includes a CSS snippet panel similar to the video.

## Run
Open `index.html` directly in a modern browser, or run:
```bash
python3 -m http.server 8000
```
Then visit http://localhost:8000.

## Source fidelity
The recording clearly shows the five animation names and several CSS declarations. Those labels and readable declarations are retained in the page's code panels. Some declarations are too small or partly obscured in the video; the visual effects and any incomplete CSS have been reconstructed to provide a complete working demo. This is a frontend-only project with no build dependencies.
